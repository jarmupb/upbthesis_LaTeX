# LaTeX class for writing theses at Universidad Pontificia Bolivariana

**upbthesis.cls** is a LaTeX class for writing your thesis at UPB.  
*Knowing how to write using LaTeX is a prerequisite*.

The current and recommended version is **[v3](https://github.com/jarmupb/upbthesis_LaTeX/tree/master/v3)** —
the class updated for **APA 7** (7th edition) in LaTeX: modern UTF-8 encoding,
`babel`, the UPB logo on the title page, and automatic APA-style headings,
tables, figures and bibliography (via `biblatex`). The classic Vancouver/ICONTEC
format is still available as an option. **All the links below point to v3.**

You have the following possibilities:
- To download a .zip bundle with all the relevant files [click here](https://github.com/jarmupb/upbthesis_LaTeX/blob/master/v3/upbthesis.zip).
- To find the raw .cls file <a href="https://github.com/jarmupb/upbthesis_LaTeX/blob/master/v3/upbthesis.cls" download>[click here]</a>.
- To explore the folder that contains all the files [click here](https://github.com/jarmupb/upbthesis_LaTeX/tree/master/v3).
- To see the documentation [click here](https://github.com/jarmupb/upbthesis_LaTeX/blob/master/v3/README.md).

For you to know, there are three versions:
- ~~v1_legacy: this .cls version organizes the thesis by sections, as it is usually done in, e.g., articles. I consider this version legacy, because I don't have intentions to further improve it.~~
- ~~[v2](https://github.com/jarmupb/upbthesis_LaTeX/tree/master/v2): this .cls organizes the thesis by chapters and, optionally, by parts. This one is more like the standard book template.~~
- **[v3](https://github.com/jarmupb/upbthesis_LaTeX/tree/master/v3): a modernized, APA 7 version of v2 — UTF-8, `babel`, the UPB logo on the title page, and `biblatex` (APA 7). This is the recommended version; see [v3/README.md](https://github.com/jarmupb/upbthesis_LaTeX/tree/master/v3) for details.**
